# SEM-002: file has no page

**Error**: the page doesn't build until this is fixed.

A file you build is a page: everything in it goes inside `page(...) { }`, which also gives it its title and
description. Files with only components and layouts, for other files to import, pass `hypra check` but
can't be built themselves.

## Fails

```hypra fails SEM-003
h1 "Shoes"
p "All our running shoes."
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "All our running shoes."
}
```
