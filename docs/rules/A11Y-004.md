# A11Y-004: action has no label

**Error**: the page doesn't build until this is fixed.

An `action` becomes a button, and its text is the button's label. Without it, people see an empty button,
screen readers announce just "button", and AI agents get a tool with no description.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  action("cart.add", id: 42)
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  action("cart.add", id: 42) "Add to cart"
}
```
