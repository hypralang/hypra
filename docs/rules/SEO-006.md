# SEO-006: description too short or too long

**Warning**: the page still builds, but this is most likely a mistake.

Search results show the description under the title. Too short, and search engines replace it with any text
from the page; over about 160 characters, they cut it off. Aim for 50 to 160 characters that summarize the
page; Chinese, Japanese and Korean characters count twice, as they show twice as wide.

## Fails

```hypra fails
page(title: "Shoes", description: "Running shoes.") {
  h1 "Shoes"
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"

}
```
