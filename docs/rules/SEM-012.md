# SEM-012: id used more than once

**Warning**: the page still builds, but this is most likely a mistake.

An `id` names one element. Links to `#reviews`, labels, scripts and ARIA references all find only the first
of two, so the second one silently doesn't work.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  section(id: "reviews") { h2 "Reviews" }
  section(id: "reviews") { h2 "Questions" }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  section(id: "reviews") { h2 "Reviews" }
  section(id: "questions") { h2 "Questions" }
}
```

In a loop, build the `id` from data: `id: "shoe-{shoe.id}"`.
