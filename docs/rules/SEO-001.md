# SEO-001: page has no title or description

**Error**: the page doesn't build until this is fixed.

The title names the page in search results, browser tabs and bookmarks, and the description is the text
under it in search results and link previews. Without one, search engines take any text from the page.

## Fails

```hypra fails
page(title: "Shoes") {
  h1 "Shoes"
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"

}
```
