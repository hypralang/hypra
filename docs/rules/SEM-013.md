# SEM-013: lang isn't a language code

**Warning**: the page still builds, but this is most likely a mistake.

Screen readers choose their voice from the page's language, and browsers their translation offer and
hyphenation. They understand codes like `en`, `de` or `pt-BR`, not names like `English`.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.", lang: "English") {
  h1 "Shoes"

}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.", lang: "en") {
  h1 "Shoes"

}
```
