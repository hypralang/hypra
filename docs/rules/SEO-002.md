# SEO-002: title too long

**Warning**: the page still builds, but this is most likely a mistake.

Search results show about the first 60 characters of a title and cut the rest. The title counts with what
the layout adds, like `" | Shop"`; Chinese, Japanese and Korean characters count twice, as they show twice
as wide.

## Fails

```hypra fails
page(title: "Running Shoes for Men and Women: Road, Trail and Racing Shoes in Every Size", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
}
```

## Fixed

```hypra passes
page(title: "Running Shoes: Road, Trail and Racing", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
}
```
