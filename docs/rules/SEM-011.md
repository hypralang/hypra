# SEM-011: element doesn't belong in head

**Error**: the page doesn't build until this is fixed.

The `<head>` holds information about the page, not content: `meta`, `link`, `script`, `style`, `base`,
`noscript` and `template`. Browsers move anything else into the body.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  head {
    link(rel: "stylesheet", href: "/app.css")
    img("/pixel.gif", decorative: true)
  }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  head { link(rel: "stylesheet", href: "/app.css") }
  img("/pixel.gif", decorative: true)
}
```
