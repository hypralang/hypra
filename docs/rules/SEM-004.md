# SEM-004: image or video has no source

**Error**: the page doesn't build until this is fixed.

An image or video without a `src` shows nothing. The source is the element's main attribute, so it comes
first and needs no name.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  img(alt: "Runner X in blue, side view")
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  img("/img/runner-x.jpg", alt: "Runner X in blue, side view")
}
```
