# SEM-010: head in the wrong place

**Error**: the page doesn't build until this is fixed.

`head` adds tags to the page's `<head>`, so it goes directly inside a page, layout or component, not inside
another element.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  section {
    head { link(rel: "stylesheet", href: "/sale.css") }
    p "All our running shoes."
  }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  head { link(rel: "stylesheet", href: "/sale.css") }
  section { p "All our running shoes." }
}
```
