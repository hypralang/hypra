# LEX-001: unexpected character

**Error**: the page doesn't build until this is fixed.

A character that has no meaning in Hypra outside a string. A semicolon at the end of a line, a habit from
JavaScript or PHP, is the usual one.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "Free returns within 30 days.";
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "Free returns within 30 days."
}
```
