# SEO-003: more than one h1

**Error**: the page doesn't build until this is fixed.

The `h1` is the page's main topic, for search engines and for screen reader users, who often jump to it
first. Sections below it are `h2`.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  h1 "Trail shoes"
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  h2 "Trail shoes"
}
```

A design that really needs two, like a headline split in two lines, can switch the rule off with `allow("SEO-003") "the reason"`.
