# SEO-005: canonical URL isn't absolute

**Warning**: the page still builds, but this is most likely a mistake.

The canonical URL tells search engines which address is the real one when a page has several, like with
`?ref=` or `?sort=`. They only follow a full URL with `https://` and the domain.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.", canonical: "/shoes") {
  h1 "Shoes"

}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.", canonical: "https://shop.example.com/shoes") {
  h1 "Shoes"

}
```
