# A11Y-012: ARIA name or state on a div without a role

**Warning**: the page still builds, but this is most likely a mistake.

A `div` or `span` is nothing to a screen reader, so most of them ignore an `aria-label` or ARIA state on
it. Use an element that means something, or give the `div` a role.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  div(aria-label: "Shoe sizes") { p "EU 38 to 47" }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  section(aria-label: "Shoe sizes") { p "EU 38 to 47" }
  div(role: "group", aria-label: "Colors") { p "Blue, black, white" }
}
```
