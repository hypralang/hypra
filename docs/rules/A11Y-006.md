# A11Y-006: heading level skipped

**Warning**: the page still builds, but this is most likely a mistake.

Screen reader users move through a page by its headings, and the levels are its outline: an `h3` right after
the `h1` sounds like a section is missing. Pick the level by the structure, and the size with CSS.
([WCAG 1.3.1](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships))

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  h3 "Trail shoes"
  p "Grip for wet rock and mud."
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  h2(class: "text-base") "Trail shoes"
  p "Grip for wet rock and mud."
}
```
