# A11Y-009: iframe has no title

**Warning**: the page still builds, but this is most likely a mistake.

Screen readers announce a frame by its title. Without one, people hear "frame" and have to go inside to find
out whether it's a map, a video or an ad. ([WCAG 4.1.2](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value))

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  iframe(src: "https://www.openstreetmap.org/export/embed.html?bbox=13.37,52.51,13.39,52.52")
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  iframe(src: "https://www.openstreetmap.org/export/embed.html?bbox=13.37,52.51,13.39,52.52", title: "Map of our store in Berlin")
}
```
