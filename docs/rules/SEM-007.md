# SEM-007: imported file contains a page

**Error**: the page doesn't build until this is fixed.

`use` imports components and layouts. A file with a page in it is a page of its own; importing it would put
two pages in one. Move what both pages share into a component.

```hypra file about.hypra
page(title: "About us", description: "Who we are: a small team of runners selling the shoes we run in.") {
  h1 "About us"
}
```

```hypra file components/team.hypra
component Team {
  p "A small team of runners selling the shoes we run in."
}
```

## Fails

```hypra fails
use "about.hypra"

page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
}
```

## Fixed

```hypra passes
use "components/team.hypra"

page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  Team
}
```
