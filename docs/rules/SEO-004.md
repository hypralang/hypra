# SEO-004: page has no h1

**Warning**: the page still builds, but this is most likely a mistake.

The `h1` says what the page is about, to search engines and to screen reader users, who often jump to it
first.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  p "All our running shoes."
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "All our running shoes."
}
```
