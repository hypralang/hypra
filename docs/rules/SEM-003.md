# SEM-003: element in the wrong place

**Error**: the page doesn't build until this is fixed.

Some things can only be in one place: components and layouts are defined at the top of a file, `props` and
`head` go directly inside the page, `field` inside a form.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  component Badge(text: Text) { span(class: "badge") "{text}" }
}
```

## Fixed

```hypra passes
component Badge(text: Text) { span(class: "badge") "{text}" }

page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  Badge(text: "New")
}
```
