# SEM-006: slot outside a component or layout

**Error**: the page doesn't build until this is fixed.

`slot` marks where a component or layout puts the content it's given. In a page there's nothing to put
there.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  main { slot }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  main { p "All our running shoes." }
}
```
