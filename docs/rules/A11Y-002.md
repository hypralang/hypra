# A11Y-002: link has no text

**Error**: the page doesn't build until this is fixed.

A link with nothing in it is announced as just "link", or by its address read out letter by letter. It
happens most with icon links: an icon that's only decoration names nothing. ([WCAG 2.4.4](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context))

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  a("/cart")
  a("/account") { img("/icons/user.svg", decorative: true) }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  a("/cart") "Cart"
  a("/account", aria-label: "Your account") { img("/icons/user.svg", decorative: true) }
}
```

An icon link gets its name from `aria-label`, or from an image with alt text that says where it goes.
