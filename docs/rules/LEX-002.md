# LEX-002: unterminated string

**Error**: the page doesn't build until this is fixed.

A string is missing its closing `"`. Strings end on the line they start; text over several lines goes
between `"""`.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "Free returns within 30 days.
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "Free returns within 30 days."
  p """
    Every pair ships in 2 days.
    Returns are free.
    """
}
```
