# LEX-003: unknown escape in a string

**Error**: the page doesn't build until this is fixed.

A backslash in a string starts an escape: `\"` for a quote, `\\` for a backslash, `\n` for a new line
and `\t` for a tab. Any other letter after it is a mistake, often a Windows path.

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "Exports are saved to C:\shop\orders."
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p "Exports are saved to C:\\shop\\orders."
}
```
