# A11Y-011: autoplaying video isn't muted

**Warning**: the page still builds, but this is most likely a mistake.

Sound that starts on its own startles people and talks over screen readers. Browsers block autoplay with
sound anyway, so the video wouldn't start.
([WCAG 1.4.2](https://www.w3.org/WAI/WCAG22/Understanding/audio-control))

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  video("/videos/hero.mp4", captions: "/videos/hero.vtt", autoplay: true)
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  video("/videos/hero.mp4", captions: "/videos/hero.vtt", autoplay: true, muted: true)
}
```
