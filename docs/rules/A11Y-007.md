# A11Y-007: link text doesn't say where it goes

**Warning**: the page still builds, but this is most likely a mistake.

Screen reader users often go through a list of a page's links, out of context. "Click here" and
"read more" then say nothing. Search engines read link text too, to learn what the target page is about.
([WCAG 2.4.4](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context))

## Fails

```hypra fails
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p { "Our sizes run small. " a("/sizes") "Click here" " for help." }
}
```

## Fixed

```hypra passes
page(title: "Shoes", description: "All our running shoes, from light racers to trail shoes.") {
  h1 "Shoes"
  p { "Our sizes run small; the " a("/sizes") "size guide" " helps you pick." }
}
```

The words are checked in the page's language (`lang`): English, German, French, Spanish, Portuguese,
Italian and Dutch, so `"Hier klicken"` is flagged on a German page. Pages in other languages aren't checked
for them.
